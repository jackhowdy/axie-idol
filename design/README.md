# Design explorations

Mockups and explorations made while the game was being designed. They are **not** the shipped UI:
several show features that Round 1 does not have (an egg, a feed, quests, duo photos, cards). The
shipped screens are rendered by `src/buddyHtml.ts`.

`*.dc.html` files are design canvases (open them in a browser). `canvas.json` files lay the
artboards out. `buddy/` holds the one-Axie game's explorations; the files beside this one belong to
the earlier camera prototype.
