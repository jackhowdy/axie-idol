# 3D Mixer Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every face in the game (18 cast + Golden Axie + every owned Axie) is an animated 3D character on the Snap camera, using Sky Mavis's Three.js Axie Mixer 3D, with a 3D "base part" downgrade so no Axie ever falls back to 2D.

**Architecture:** The mixer library is vendored (built `dist/` from the public alpha repo, `vendor/axie-mixer3d/`) and its 512 MB asset pack is copied to `public/assets/axie/` (git-ignored, reproducible via `scripts/copy-mixer-assets.mjs`). A new `src/axie3d.ts` owns one WebGL renderer + one mixer instance and exposes the same surface as `sticker3d.ts` (`canvas, ready, setLean, renderNow, pause, resume, dispose`) plus `load(spec)` where a spec is `{ kind: 'genes', genes }` or `{ kind: 'descriptor', descriptor, gold?: boolean }`. `main.ts` routes: kit/starter GLB faces → existing `sticker3d`; numeric cast, owned Axies, Olek, Agonia Echo, Golden → `axie3d`. The server gains `GET /api/axie/:id` (genes via the keyed gateway, cached in a new `axies` store). Custom faces (Olek, villain, golden) are descriptors computed from the creator catalog in `src/castDescriptors.ts`.

**Tech Stack:** three 0.178.x (downgrade from 0.185), `@jaatster/threejs-axie-mixer3d-public` 0.1.0-alpha (vendored), existing Vite/TS app, node:test.

## Global Constraints

- Rights: pack and code used only inside this Vibeathon project; keep `RIGHTS.md` and `THIRD_PARTY_NOTICES.md` alongside the vendored copy; never redistribute the pack.
- Asset pack is never committed to git; `npm run copy-mixer-assets` recreates `public/assets/axie/` from the clone path recorded in the script.
- Existing tests stay green; API additions only (no behaviour change to posts/quests).
- 3D downgrade policy: missing part variant → same part, normal skin (`skin 0`); missing stage 2 → stage 1. Never skip a part, never fall back to 2D.
- Phone budget: one mixer character live on Snap at a time; group-photo extras are still images snapshotted from the 3D model.
